# Blue Moon / Blue Moon Legends (Reiner Knizia)

Дуэльная карточная игра Рейнера Книзии (Kosmos 2004 → Fantasy Flight; сборник **Blue Moon Legends**, 2014). Это **не** living-line LCG в смысле FFG (Netrunner / LotR / CoC): фиксированные колоды народов + правила кастомизации, без бустеров. FFG исторически относила её к семейству «LCG-подобных» (фиксированный кардпул). Пользовательский индекс — рядом с LCG-заметками.

Закладок Chrome по «Blue Moon» **не найдено** (Default + Profile 2; `_bookmarks_extracted.txt` тоже пуст по теме). Ниже — проверенные стартовые ссылки (сент. 2026 MSK).

Не путать с **Blue Moon City** (отдельная евро-настолка в том же мире, 2–4 игрока) — правила/компоненты несовместимы с карточной игрой.

## Обзоры / принцип игры

Emissaries/Inquisitors/Spirits). В Legends — всё в одной коробке (~bridge-size карты); в 1-м изд. — tarot-size + отдельные бустеры-колоды.

## Базы карт / колодостроение

Отдельного «RingsDB / ConquestDB / Battle Network» для Blue Moon **нет**. Кардпул конечный и небольшой (~все карты в одной коробке Legends); «билдер» = Advanced Concepts + таблица/листы на BGG.

- **Официальные правила кастомизации** — в [Advanced Concepts](https://tesera.ru/images/items/405253/BlueMoonAdvancedRulebook.pdf): лидер народа + колода; карты чужих народов в сумме **moon value ≤ 10** (если Emissary/Inquisitor не меняют лимит); Buka families, draft variant и т.д.
- Преконструкт: 9 peoples decks в Legends (Vulca, Hoax, Mimix, Flit, Khind, Terrah, Pillar, Aqua, Buka) — играть «из коробки» без билдинга.
- Списки/стратегии по колодам — Appelcline (ссылки выше) + файлы на [BGG Blue Moon → Files](https://boardgamegeek.com/boardgame/9446/blue-moon/files) / [Legends → Files](https://boardgamegeek.com/boardgame/147154/blue-moon-legends/files) (strategy primers, icon refs; HTML ботов 403).
- Mnemosyne FAQ (Wayback выше) — сверка названий 1-е↔2-е изд. и clarifications по билдингу.
- Proxy Nexus / онлайн-декбилдеры под Blue Moon **не заявлены** (на сент. 2026 публично — Netrunner / LotR / AGOT и др.; Blue Moon нет).

## Соло / solo

Официально игра **строго 2 игрока**. Встроенного автомата у Kosmos/FFG нет. Рабочие пути сообщества:

### Цифровой AI (лучший старт для соло)
- [Blue Moon AI — Keldon Jones](https://keldon.net/bluemoon/) — EN, **бесплатный** клиент vs нейросеть; Linux source + [Windows installer](https://keldon.net/bluemoon/BlueMoonSetup1.3.2.exe) (+ [GTK 2.12.3](https://keldon.net/bluemoon/gtk-2.12.3-setup.exe) при необходимости). Поддержка базовых колод + **Buka Invasion** (не полный кардпул Legends / без Emissaries & Inquisitors). [AI FAQ](https://keldon.net/bluemoon/faq.html). Проверено 200 (сайт + архивы).
- Тот же AI — источник картинок для TTS-мода `2886497195`.

### Бумажный / PnP автомат
- **Unofficial solo: Blue Moon against Drake** — фан-вариант на BGG Files у [Blue Moon (9446)](https://boardgamegeek.com/boardgame/9446/blue-moon/files): автооппонент Drake (кубики). Открывать список Files в браузере (ID filepage в этом прогоне не верифицировался отдельно — не выдумывать).
- Режим **draft** и match/crystals в Advanced Concepts — не соло, но расширяют «из коробки» без второго постоянного оппонента-человека хуже, чем AI.

**Итог:** для соло начинать с **Keldon Blue Moon AI**; бумажный Drake — опционально с BGG Files. Для «полного» Legends (все народы + Emissaries) — TTS vs человек или hotseat.
