# Blue Moon / Blue Moon Legends (Reiner Knizia)

Дуэльная карточная игра Рейнера Книзии (Kosmos 2004 → Fantasy Flight; сборник **Blue Moon Legends**, 2014). Это **не** living-line LCG в смысле FFG (Netrunner / LotR / CoC): фиксированные колоды народов + правила кастомизации, без бустеров. FFG исторически относила её к семейству «LCG-подобных» (фиксированный кардпул). Пользовательский индекс — рядом с LCG-заметками.

Закладок Chrome по «Blue Moon» **не найдено** (Default + Profile 2; `_bookmarks_extracted.txt` тоже пуст по теме). Ниже — проверенные стартовые ссылки (обновление окт. 2026 MSK).

Не путать с **Blue Moon City** (отдельная евро-настолка в том же мире, 2–4 игрока) — правила/компоненты несовместимы с карточной игрой. Роман *Blue Moon* (Frank Rehfeld, DE) — лор, не правила.

### Издания (различать)

| | **Blue Moon (v1)** | **Blue Moon Legends (v2)** |
|---|---|---|
| Годы / формат | 2004–, expandable ECG: базовый сет (Vulca+Hoax) + отдельные people decks + 2× E&I + Buka Invasion | 2014, **одна коробка** со всеми картами (~344) |
| Размер карт | Tarot (~7×12 см) | Bridge (стандарт FFG green sleeves) |
| Правила | 1 rulebook + rulesheets E&I / Buka | **Rulebook** (преконструкт) + **Advanced Concepts** (FAQ/deckbuild/draft) |
| Языки | EN, DE, NL (частично), FR (частично) | EN, DE, PL, JP, ES, ZH |
| Статус | OOP; отдельные колоды на вторичке | OOP; вторичка / сканы |

Оба издания **играют одинаково по смыслу** (FAQ Dearlove). Можно играть v1-колоду против v2-колоды (термины фаз разные); смешивать карты разных изданий в одной колоде нельзя.

#### Ключевые тезисы FAQ (Dearlove) — шпаргалка
- **Издания играют одинаково** по смыслу; FAQ v1 применим к Legends (меняется только wording). Единственное отличие — **handling irregularity / backtracking**: v2 — forgiving в friendly, penalty на турнире на усмотрение организатора.
- **Единственный явный ruling:** shields **являются icons** (DE rulebook; EN v1 был неоднозначен). Важно vs Mad Mike Magpie и т.п.
- **End of game / deck-out:** не проигрываешь только из‑за пустой руки/колоды, если у кого-то есть дракон(ы). При трёх драконах в центре побеждает тот, кто **последним** имел карты в руке.
- **Retreat advice (Final Points):** retreat даже когда можно продолжать — особенно при 4–5 картах у оппонента в combat/support или при сильных supports; баланс руки; трек mutants/signature.
- **Banned cards:** нет (Chosen of Nature временно банили в Liga — Knizia против, бан снят).
- **E&I:** emissaries → ~40-card на преконструкт (+3 people +7 emissary); inquisitors только с deckbuilding (+cards/+moons/+power). Inquisitor ≠ нейтрален (сильнее без него).
- **Buka:** ships (load/land; Buka FREE с корабля) + bluffing (FIRE/EARTH/EMPTY BLUFF; call → риск 2+ dragons); семьи Ba–Bf (+5 карт к преконструкту); Sea Moon promo = Buka для moons, но **не** в преконструкт/семьях.
- **Произношение (playtesters):** Khind ≈ «Kinnеd»; Hyla ≈ «Huwla».

## Именование и маркировка карт (v1 Blue Moon / v2 Legends)

Источник: [Mnemosyne FAQ — legendsfaq.txt](https://www.mnemosyne.uk/bgames/bluemoon/legendsfaq.txt) (Christopher Dearlove).

### Имена и нумерация

- **Имена карт и номера в v2 (Blue Moon Legends) те же, что в v1 (Blue Moon).**
- Все карты v1 есть в v2, включая пять промо (две впервые на EN).
- Играют одинаково по смыслу; FAQ v1 применим к v2 (формулировки правил другие).
- **ID карты = народ/тип + номер** (не буква колоды). Буква колоды = *в какой преконструкт-колоде лежит физическая копия* (может отличаться от народа).

### Маркировка на карте

| | **v1 Blue Moon** | **v2 Blue Moon Legends** |
|---|---|---|
| Народ / тип (non-people) | Слово (название народа / типа) | **Символ** вместо слова |
| Преконструкт-колоды | Буква колоды; у Buka — ещё номер семьи | Та же **буква** (и family number у Buka) |
| Emissaries & Inquisitors | **X1 / X2** на картах | X1/X2 **убраны**; у non-people метка эмиссара **Tu / Fa / Ri / Ne** (вместо списка на карте эмиссара) |
| Где смотреть код колоды | Нижний **левый** угол: под именем народа и номером, слева от moons | Похожая инфа в нижнем **правом** углу; **без** X1/X2 |

Буквы колод v1: **V, H, M, F, K, T, P, A**; E&I — **X1/X2**; Buka Invasion — **Ba–Bf** (вторая буква = семья); промо без указания колоды (Buka ship — Buka без семьи).

Диапазоны номеров (каталог): people `000`–`032` (лидер 000); Mutant `101`–`110`; Crystal/Ach `201`–`203`; Interference `401`–`407`; Inq `411`–`414`; Emis `500/600/700/800`; Tutu `501`–`508`; Hyla `601`–`608`; Spirit/Promo `901`–`904`.

### Что переименовали в правилах (не имена карт)

В v2 сменились **названия фаз**, описание зон influence, иконка **PROTECTED → PROTECT** (термин «PROTECTED card» остался), на картах «may not» → «cannot». Арт тот же (кроп/зум/отражение; у пяти Buka B.P. в v2 разные маски вместо одной общей картинки).

Фазы v1 → v2: Beginning of Turn→Beginning, Leadership→Leadership, Retreat from Fight?→Engagement, Character→Character, Booster/Support→Booster/Support, Announce Power→Power, Refresh Hand→Refresh, End of Turn→End.

## Конвенция имён файлов сканов — BML v2

Схема для физического архива сканов **Blue Moon Legends** (не для AI/Lackey). Опирается на Mnemosyne: **people/type + number = primary ID**; буква колоды — отдельное поле.

### Шаблон

```text
BML_<TYPE><NNN>_<DECK>[_<EMI>]_<Slug>[_<LANG>][_<side>][_<dpi>][_alt...] .ext
```

### Примеры

- `BML_Vulca000_V_Inferno_EN.jpg`
- `BML_Mimix006_V_Heroine_of_the_Great_Plains_EN.jpg` — народ Mimix, лежит в колоде Vulca
- `BML_Emis500_X1_Tu_GashGash_Princess_of_the_Tutu_EN.jpg`
- `BML_Hyla601_X1_Fa_Thurus_EN.jpg`
- `BML_Interference402_X1_Shame_on_you_EN.jpg`
- `BML_Crystal201_X2_Likas_Blessing_EN.jpg`
- `BML_Ship028_Ba_Sea_Falcon_EN.jpg`
- Рубашки: `BML_back_EN_01.jpg`, `BML_back_EN_02.jpg`

### Поля

| Поле | Смысл |
|---|---|
| `BML` | Префикс архива Blue Moon Legends (physical / multisheet crop) |
| `TYPE` | Народ / семейство: `Vulca`, `Hoax`, `Mimix`, `Flit`, `Khind`, `Terrah`, `Pillar`, `Aqua`, `Buka`, `Mutant`, `Inq`, `Hyla`, `Tutu`, `Emis`, `Ship`, `Crystal`, `Interference`, `Promo` |
| `NNN` | 3-значный номер с ведущими нулями (печатный / каталожный) |
| `DECK` | Буква преконструкт-колоды этой копии (может ≠ народу): `V/H/M/F/K/T/P/A`, Buka `B`/`Ba`–`Bf`, E&I `X1`/`X2`, промо без колоды — `X` |
| `EMI` | Опционально метка эмиссара: `Tu` / `Fa` / `Ri` / `Ne` (для Emis, Tutu, Hyla) |
| `Slug` | EN-название; пробелы → `_`; без Windows-illegal и лишней пунктуации |
| `LANG` | Язык текста на лице (`EN` для этой коллекции) |
| `side` | Для лица опускать; рубашки — отдельный `BML_back_EN_##` |
| `dpi` | Писать, если известен EXIF/замер; иначе опускать (~540 est. при poker footprint) |
| `alt…` | Альтернативный кроп (`altg46`, …), если несколько файлов с одним ID |
| `.ext` | Сейчас `.jpg`; целевой долговременный формат — **PNG** (lossless; массово не конвертировать пока) |

### Критическое правило

**People/type + number = primary ID.** Буква колоды = в какой преконструкт-колоде лежит физическая карта. Пример: Mimix-героиня в колоде Vulca → `BML_Mimix006_V_…`.

Legacy bracket-имена `NNN Name [Race, Set].jpg` → TYPE из Race (`Inter`→`Interference`, `Infl`→`Hyla`, `Ach`→`Crystal`, …); Set → `DECK`.

Особые случаи: рубашки без читаемого лица — только `BML_back_…`; корабли — `TYPE=Ship`; не выдумывать EMI/DECK при нечитаемом — флаг в map/STATUS.

## Стратегия / анализ / walkthrough

Источники этого прогона (окт. 2026 MSK): [BGG #1863347](https://boardgamegeek.com/thread/1863347/my-general-blue-moon-strategy-with-analysis-of-eac) (+ [Reddit mirror](https://www.reddit.com/r/boardgames/comments/75x0cy/blue_moon_strategy_with_analysis_of_each_faction/)); outbound Gone Gaming Part 1–2; Mnemosyne Final Points / Buka / E&I. BGG HTML с ботов — **403** (Cloudflare); текст треда сверялся через search snippets + Reddit mirror.

### Общие принципы
- Blue Moon — **resource / attrition game**: не убивать каждую стычку «в ноль»; часто выгоднее **retreat early**, чем отдать **double dragon** (6+ карт у победителя).
- Два режима (BGG #1863347): **attrition** (тянуть бой, жечь карты оппонента, копить к double-dragon ambush) и **blitz** (резкий скачок силы / overkill). Выбор зависит от народа.
- Держать **баланс руки** (characters vs boosters/supports); «бесполезные» карты — осознанно сжигать ради refresh / не застрять без characters.
- Трекать **mutants** и signature-карты обеих колод; знать условия мутантов до старта.
- Mnemosyne Final Points (3 совета): (1) retreat при 4–5 картах у оппонента в combat/support или против сильных supports; (2) баланс руки, не бояться waste ради draws; знать endgame при драконах в центре; (3) знать обе колоды / contested element / threats.
- Не отдавать Vulca (и любому) лёгкий double-dragon: держать wins на одном драконе, если можете (коммент Gone Gaming Part 1).

### Разборы по народам

| Народ | Стиль (кратко) | Источники |
|---|---|---|

| **Hoax** | Support-heavy, контроль, skill-intensive; fire слегка сильнее earth | Gone Gaming P1; BGG |

| **Terrah** | Диктовать Earth; restrictions; **Earthquake** чистит area / ломает ambush | BGG / Reddit |
| **Pillar** | Info (open hand) + caterpillars; короткие бои; discard чтобы не инициировать | BGG / Reddit |
| **Aqua** | Blitz из необходимости (мало characters, много Free S/B); flood; Immortality | BGG / Reddit; RPGnet Aqua |

#### Детали по народам (из BGG #1863347 + Gone Gaming)

**Vulca (attrition → ambush).** Высокие Fire (Flamebreath 7, Scorch 6, Volcanic Gauntlets, Elemental Enchantment→6). Лучшие значения тратить только когда выигрываете **двух** драконов: low cards → прыжок с 4‑й на 6‑ю карту. Earth не «слабый» — не отдавать элемент даром. Ключи: Charm Holy Dragon (8 Fire→dragon), Wall of Fire, Cast Cataclysm / Cinder / Pandemonium vs support-heavy. Counter: не пускать к 6 картам; иметь ответ на один high spike.

**Hoax (control / skill).** Слабые characters (ядро — пять 2/2 с текстом); сила в supports + leadership. Brain Drain (≤1 card/turn) — дуэль-киллер на 6‑карточном винe; Duplicator of Strength + Potion/Boomerang. Muster Reinforcements → Trigger Brainstorm (draw 5 → dump supports). Retrievables: не класть >1 в бой без double-dragon. Counter: throw duels чтобы сжечь supports/retrievables; brute-force jump to 6–7 до росписи supports.

**Mimix (blitz).** Пары Amazons; shamans (2/2, часть со STOP) играть **рано** / на low lead; Call Spirits собирают пары. Overkill — норма. Heroine of the High Flames без пары в колоде; Virgins 6/1 и 1/6 — часто соло. Counter: press high numbers быстро; anti-pair / «только special-effect characters»; early Support.

**Flit (retrieve + burst).** Low character → retrieve → rinse; boosters парами / Commence Mega Launch. Не копят до 6 карт, пока не «жертвуют» Flit. Counter: считать retrieved; не играть ≤ значения известного retrieve; anti-booster; иногда retreat только чтобы убить сильный retrieve.

**Khind (attrition via GANG).** Похож на Mimix, но автор #1863347 предпочитает **не** blitz: Yellow Gang (и др.) раскладывать **по ходам** (1→2→3→…), а не все сразу — GANG работает across turns. Counting + гибкий pressure.

**Aqua (blitz из нужды).** Мало characters, много Free supports/boosters → надо **тратить** карты (даже без полного эффекта), иначе auto-lose без characters. Yin/Yang FREE; flood-combo (Torrential+Tidal → immediate retreat после хода); Administer Water of Immortality (reshuffle).

**Terrah (Earth dictate + disrupt).** Не отдавать старт боя (Earth preference). Restriction-тексты могут force auto-retreat. **Provoke Earthquake** — сброс combat area оппонента: ломает double-dragon ambush и ставит вас в позицию win-2 / lose-1.

**Pillar (info + caterpillars).** Слабые characters; open/semi-open hand + FREE caterpillars (discard-pressure). Автор #1863347: combo «смотреть руку → дешёвые винны» слабо работает; лучше укорачивать число боёв (discard / decline initiation), максимизируя ценность caterpillars.

**Buka (ships + bluff).** Load/land ships (burst; Buka FREE с корабля). Bluff face-down как support value 2; safe только правильный element BLUFF — иначе call даёт оппоненту dragon + ваш retreat (часто ещё dragon). Пустой/неверный bluff — иногда, чтобы оппонент перестал звать. Семьи Ba–Bf = +5 к другой колоде.

**E&I / Inquisitors.** Emissaries: GashGash / Farquhar / Ri Cha / Nekra-Khati — разный микс interference/Tutu/Hyla/crystal/mutant. Inquisitors: Swift-Fist (+1 dragon start), Razor-Mind (+5/+5 REPLACE), Grease-Palm (+10/+15), Weave-Tongue (+15/+10 +draw).

### Цифровой AI (лучший старт для соло)
- [Blue Moon AI — Keldon Jones](https://keldon.net/bluemoon/) — EN, **бесплатный** клиент vs нейросеть; Linux source + [Windows installer](https://keldon.net/bluemoon/BlueMoonSetup1.3.2.exe) (+ [GTK 2.12.3](https://keldon.net/bluemoon/gtk-2.12.3-setup.exe) при необходимости). - Тот же AI — источник картинок для TTS-мода `2886497195`.

### Бумажный / PnP автомат
- **Unofficial solo: Blue Moon against Drake** — фан-вариант на BGG Files у [Blue Moon (9446)](https://boardgamegeek.com/boardgame/9446/blue-moon/files): автооппонент Drake (кубики). Открывать список Files в браузере (ID filepage в этом прогоне не верифицировался отдельно — не выдумывать).

**Итог:** для соло начинать с **Keldon Blue Moon AI**; бумажный Drake — опционально с BGG Files. Для «полного» Legends (все народы + Emissaries) — TTS vs человек или hotseat.
