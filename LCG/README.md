## Как пользоваться

- В каждом файле блоки: правила, обзоры, гайды, компаньоны, **базы карт / колодостроение**, онлайн, **сканы карт / прокси-изображения**, комьюнити, плюс отдельный раздел **Соло / solo**.
- Для Netrunner **эпохи FFG и NISEI/NSG разделены** — не смешивать кардпулы и форматы без понимания; соло тоже разбит на FFG vs NSG/кросс-эра (DASH совместим с обоими кардпулами). **Сканы FFG @600dpi ≠ официальный PnP NSG.**
- Базы/билдеры ориентиры: Netrunner → NetrunnerDB (+ Acoo только FFG≤Core 2.0); LotR → RingsDB + Hall of Beorn; CoC → Battle Network (+ TCGBuilder / Minet offline); Conquest → ConquestDB + Iridial (+ CardPlace.ru справочно); **Blue Moon** → отдельного онлайн-билдера нет (Advanced Concepts + BGG Files; соло — Keldon AI / TTS).
- Сканы/прокси: предпочтение ссылкам на **обсуждения/индексы** (Reddit, Proxy Nexus, Apoka); прямые Drive/Mega из постов могут ротироваться и не копируются как «вечные».
- Мёртвые сайты — через [Wayback Machine](https://web.archive.org/).
- Источники: черновики в этой папке, Chrome-закладки (`Onboard`, `Дети/Игры`), веб-поиск + проверка HTTP.
