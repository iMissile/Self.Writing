# Переименование видеофайлов (Кинопоиск + ffprobe)

Канон с библиотеки `F:\` (образцы: `Incoming\241119 - Harry Potter`, `Videobank\Детские`,
`Сериалы\The Big Bang Theory`, `Сериалы\Billions`).

---

## Фильмы и киноциклы

### Формат имени

**Иностранный фильм:**
```text
{Original} - {Русское} ({год}) [{качество}].{ext}
```

**Русский / совпадает с оригиналом:**
```text
{Русское} ({год}) [{качество}].{ext}
```

**Киноцикл (фильмы с номером, не сериал):**
```text
{NN}. {Original} - {Русское} ({год}) [{качество}][-группа].{ext}
```

Примеры:
- `Aladdin - Аладдин (2019) [1080p] ExKinoRay.mkv`
- `Teddys Christmas - Приключения Тедди (2022) [1080p.BDRemux].mkv`
- `01. Harry Potter and the Sorcerer's Stone - Гарри Поттер и философский камень (2001) [1080p;BDRip;Extended.Cut]-SOFCJ.mkv`

### Алгоритм (фильмы)

1. **Опознать фильм** по имени, году, длительности. При нескольких совпадениях по слову — не выбирать молча (три «Момо» = три карточки).
2. **Кинопоиск:** взять русское название, оригинальное название, год **производства** (не цифровой релиз в РФ).
3. **Собрать заголовок:**
   - оригинал ≠ русское → `Original - Русское (год)`;
   - совпадают → `Русское (год)`.
4. **Качество `[…]`:**
   - разрешение — обязательно (см. ниже);
   - остальное — только то, что уже было в исходном имени, через точку: источник, Open Matte / Extended Cut, кодек, звук, Dub/Sub и т.п.;
   - порядок: разрешение → источник → особенность картинки → звук → кодек → язык/дорожки;
   - трекеры и релизеров-спам (`ELEKTRI4KA`, `UNIONGANG`, `MegaPeer`, `NNM-Club`) — выкинуть;
   - релиз-группа опционально после скобок (`ExKinoRay`, `-SOFCJ`).
5. **Windows:** убрать `<>:"/\|?*`; апостроф убирать (`Teddy's` → `Teddys`).
6. **Dry-run** таблицей «было → стало», затем переименование. Файл во вложенной папке — поднять на уровень пачки, пустую папку убрать.
7. Не склеивать с уже лежащим файлом другого года той же франшизы (`1970` ≠ `2000`).

## Сериалы (`F:\Сериалы`)

Единица хранения — **релиз-пачка** (то, что скачали одним комплектом) со своим
качеством. Внутри пачки — директории сезонов. Качество **не** дублировать на
каждый сезон и **не** уплощать пачку в плоский список `S01 […]`, `S02 […]` на корне.

Образцы в библиотеке (в т.ч. качество на сезоне, если пачка = один сезон):
- `The Big Bang Theory …\03 1-23 [720p;WEB.DL.;iTunes]\01. The Electric Can Opener Fluctuation - Флуктуации электрооткрывашки.mkv`
- `Billions …\S05 [720p;Web-DL;LostFilm]\…`
- `30 Rock …\S01 [720p]\…`

### Иерархия

```text
F:\Сериалы\{Original} - {Русское} ({годы})\
  [{разрешение}.{источник}.{озвучка}.{…}]\     # пачка релиза
    S{NN}\                                     # сезон внутри пачки
      {ep}. {Title EN} - {Title RU}.{ext}
      {ep}.{ext}
```

* **Корень сериала** — как у фильма: оригинал ≠ русское → `Original - Русское (годы)`.
  Годы — период показа (Кинопоиск).
* **Пачка релиза** — папка с `[…]` (через точку). Имя пачки = качество, без
  релиз-группы (`-DEFLATE`, `-iNGOT` не писать). Несколько сезонов из **одного**
  релиза остаются **внутри одной** пачки (`S01`, `S02`, …). Не разносить их на
  корень сериала.
* **Папка сезона** внутри пачки — просто `S{NN}` (ведущий ноль), без второго `[…]`.
  Если в исходнике пачка уже была одним сезоном с качеством на папке сезона
  (`S05 [720p;…]` как в Billions) — допустимо оставить качество на сезоне; главное
  не разорвать многосезонную пачку.
* **Два разных релиза** (разное качество/озвучка) — две пачки на корне. Один и тот
  же номер сезона может быть в обеих (`[720x400.HDRip.Amedia]\S02` и
  `[1080p.BluRay.X264.Amedia]\S02`).

### Имя файла серии

1. **Номер** в пределах сезона. Ширина 2 (`01`…`24`), если в сезоне **больше 9**
   серий; иначе без ведущего нуля (`1`…`9`).
2. **Название** — с Кинопоиска / IMDb и т.п., **если это настоящее имя**,
   не заглушка `Episode 1` / `Эпизод 1` / `Episode #2.3`:
   * оригинал ≠ русское → `{ep}. {Title EN} - {Title RU}.{ext}`
   * совпадают или русского нет → `{ep}. {Title}.{ext}`
   * заглушка или имён нет → только `{ep}.{ext}`
3. В имя файла **не** тащить разрешение, источник, кодек, озвучку —
   это на папке пачки (или сезона, если пачка = один сезон).
4. Windows: убрать `<>:"/\|?*`; апостроф убирать.

### Качество на пачке `[…]`

* **Разрешение** — обязательно, замер `ffprobe` (см. ниже). Нестандарт
  (`720x400`) — сырым `WxH`, не выдавать за `720p`.
* **Источник / кодек** (`WEB-DLRip`, `HDRip`, `BluRay`, `X264`…) — из исходных
  имён файлов пачки, через точку.
* **Озвучка** — **только** из `ffprobe` / `ffmpeg` по тегам аудиодорожек
  (`title`, `language`). Пример замера:

  ```powershell
  ffprobe -v error -select_streams a -show_entries stream_tags=title,language -of default=nw=1 "путь\к\файлу.mkv"
  ```

  В `title` есть студия (`Amedia`, `LostFilm`, `NewStudio`, …) — вписать в `[]`.
  Теги пусты — студию **не** брать из имени файла. Не подписывать наугад.
* Трекеры-спам и релиз-группы — выкинуть.
* Порядок в `[]`: разрешение → источник → озвучка → кодек → …
* Пачка однородна — достаточно замера пары файлов.

### Алгоритм (сериалы)

1. Опознать сериал (Кинопоиск): оригинал, русское, годы, число сезонов.
2. Сохранить границы **релиз-пачек** из исходной раскладки; внутри — `S{NN}`.
   Мусорные обёртки схлопнуть, пачку с несколькими сезонами не уплощать.
3. На каждую пачку: `ffprobe` видео + аудио → `[…]` на пачку; источник/кодек из имён.
4. Названия серий — из сети; при одних «Episode N» — только номер.
5. Dry-run «было → стало» (путь целиком), проверить коллизии.
6. Переименовать; пустые папки убрать. Число файлов не меняется.

Пример (Humans / Люди):

```text
Humans - Люди (2015 – 2018)\
  [720x400.WEB-DLRip]\              # был отдельный S1; title пуст → без студии
    S01\ 1.avi … 8.avi
  [720x400.HDRip.Amedia]\           # была пачка «Люди» на три сезона
    S01\ S02\ S03\
  [1080p.BluRay.X264.Amedia]\       # 1080p-пачка
    S02\ S03\
```

## Разрешение (имя + ffprobe)

Всегда вписывается. Замер:

```powershell
ffprobe -v error -select_streams v:0 -show_entries stream=width,height -of csv=p=0:s=x "путь\к\файлу.mkv"
```

Ярлык по кадру (не по одной высоте — иначе crop 1920×800 станет ложным `720p`):

1. ширина ≥ 3840 → `2160p`
2. ширина ≥ 1920 → `1080p` (в т.ч. crop вроде 1920×800)
3. высота ≥ 720 и ширина ≥ ~1280 → `720p`
4. высота ≈ 576 (±10) → `576p`
5. высота ≈ 480 / 360 → `480p` / `360p`
6. иначе — ближайший стандарт; в dry-run писать сырой `WxH`

Тег в имени сверить с ярлыком замера. Совпало или имени нет — писать ярлык. Явное враньё в имени — в итог идёт замер, расхождение в dry-run.

Прочие теги качества из контейнера не выдумывать — **кроме озвучки сериалов**,
которая читается из `stream_tags` аудио (см. выше).

## Источники полей

| Поле | Фильм | Сериал |
|---|---|---|
| Original / Русское | Кинопоиск | Кинопоиск (корень) |
| Год / годы | год производства | период показа |
| Разрешение | имя **и** `ffprobe` | `ffprobe` → на папку **пачки** |
| Источник, кодек | только исходное имя | исходные имена пачки → на папку пачки |
| Озвучка | только если уже было в имени | **только** `ffprobe`/`ffmpeg` `title`/`language` → на пачку |
| Имя серии | — | Кинопоиск/IMDb; заглушки «Episode N» не писать |
| Релиз-группа | опционально после `[]` | не писать |
| Границы пачки | — | многосезонный релиз не уплощать |

## Чек-лист перед rename

**Общее**
- [ ] Карточка Кинопоиска сверена (одноимённые / ремейки / сезоны)
- [ ] `ffprobe` по пачке: WxH и ярлык зафиксированы
- [ ] Таблица было → стало записана
- [ ] Нет коллизий имён в целевой папке
- [ ] После rename — число файлов то же, пустые подпапки убраны

**Сериалы дополнительно**
- [ ] Релиз-пачки сохранены; многосезонную пачку не уплощать
- [ ] `[…]` на пачке, внутри — `S{NN}`; не на файлах; внутри `[]` через точку
- [ ] Озвучка сверена с `ffprobe` (пусто в tags → студии в имени нет)
- [ ] Релиз-группы нет
- [ ] Имена серий — настоящие или только номер; ведущий ноль только при N>9
