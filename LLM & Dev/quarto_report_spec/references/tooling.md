# Инструменты и CLI

Правила для `lab/tools/*.py`, модулей с `main()` и любого скрипта, который
печатает результат в терминал. Отчёты Quarto сюда не входят: их вывод идёт
в HTML, а не в консоль Windows.

---

## Консоль Windows и UTF-8

**Наблюдение.** Встроенный терминал Cursor/VS Code и классический PowerShell
по умолчанию кодируют stdout/stderr как **cp1251**. Python 3.13 на Windows
наследует эту кодировку. Скрипт, который уже посчитал результат и падает на
`print` с символом вне cp1251 (`→`, `Δ`, рамки таблицы Polars), выглядит
сломанным, хотя данные и логика в порядке.

**Правило.** Каждый CLI-инструмент, печатающий человекочитаемый текст с
не-ASCII, в **начале `main()`** (до первого `print`) вызывает:

```python
if hasattr(sys.stdout, "reconfigure"):
    sys.stdout.reconfigure(encoding="utf-8")
    sys.stderr.reconfigure(encoding="utf-8")
```

`hasattr` обязателен: на старых или нестандартных потоках метода может не
быть; на Linux/macOS вызов безопасен и ничего не ломает.

**Почему в коде, а не только в окружении.**

| способ | минус |
|---|---|
| `$env:PYTHONIOENCODING = "utf-8"` в профиле PowerShell | не срабатывает, если терминал запущен без профиля или из задачи CI |
| `terminal.integrated.env.windows` в `.vscode/settings.json` | только встроенный терминал Cursor/VS Code в этом workspace |
| `chcp 65001` перед командой | легко забыть; не помогает subprocess без обёртки |
| **`reconfigure` в `main()`** | инструмент самодостаточен на любой машине и в любом вызове |

Переменная окружения и настройки терминала **не запрещаются** — они дополняют,
но не заменяют правило: исполнитель правила — сам скрипт.

**Где уже применено (образец).** `ocr_intake.py`, `diff_runs.py`, `build_gold.py`.
Новый инструмент с таблицами, стрелками в diff или русским текстом в stdout
копирует тот же блок в начале `main()`, без выноса в общий модуль: три строки
дешевле зависимости ради одной строки.

**Quarto и Jupyter.** Ячейки отчёта в HTML не страдают от cp1251. Исключение —
скрипт, который агент или человек запускает **из терминала** (`uv run python
lab/tools/…`). Именно его и закрывает это правило.

**Тест после правки.**

```powershell
uv run python lab/tools/build_gold.py --check
```

Должен завершиться с кодом 0 и строкой «→» в блоке поправок, без
`UnicodeEncodeError`.

## Минимальный набор инструментов

| инструмент | что ловит |
|---|---|
| `validate_model.py` | несогласованность предметного слоя до расчёта |
| `render_smoke.py` | ошибки в чанках за секунды вместо полного рендера |
| `diff_runs.py` | разность манифестов двух прогонов |
| `lint_methodology.py` | образцы запрещённых ходов в коде |
| `pytest -q -rs` | регрессии; `-rs` обязателен — иначе пропуски без причины |

Полный цикл правки, меняющей числа, — в `AGENTS.md` проекта; сравнение прогонов
после рендера дополняет `diff_runs`, а не заменяет snapshot-тесты.
