# Тяжёлые прогоны — в облаке

Уточнение пользователя от 2026-11-09: тяжёлые прогоны выполняются в облаке только для Tabletop и Wolfram. Для остальных проектов, в том числе АОСР/РЭКС, выбирайте место запуска по задаче и указаниям пользователя.
Планирование, разбор ошибок, проверка гипотез и выводы остаются у основного агента.
Облачный сервер и работающий на нём агент только исполняют заранее подготовленный код.
По умолчанию основной агент **формирует задания**, а владелец запускает их отдельно.
SSH/VPN, развёртывание и старт процессов не входят в подготовку задания без нового прямого поручения пользователя.

## Где выполнять

* Полный длительный pytest, массовый smoke/gate, обучение и большие оценки — облако.
  В Blue Moon AI полный набор с `ml` относится к тяжёлым.
* Локально — короткие адресные регрессии, сбор списка тестов, статические проверки,
  малые smoke и проверка упаковки. Не запускать большой набор для оценки того, сколько он займёт.
* Явное разрешение пользователя досчитать конкретный локальный хвост — исключение для этого запуска.
  Новая договорённость об облаке сама по себе не означает остановить уже идущие процессы.
  При обрыве сохранять результаты и восстанавливать остаток, если это корректно для данного набора.

## Задание исполнителю

Основной агент готовит детальное задание и проверяемый пакет по правилам репозитория:

1. Точная версия кода, входов, окружения и постановки, контрольные суммы; сервер и способ передачи —
   из указаний владельца и runbook проекта.
2. Готовые команды, рабочий каталог, порядок зависимых шагов, лимиты ресурсов, логи и exit code каждого шага.
   При ошибке исполнитель сохраняет полный вывод и останавливает зависимые шаги по указанному правилу.
3. Явный список возвращаемых файлов: исходные результаты, логи, ошибки, сведения об окружении и SHA-256 архива.

Не поручать исполнителю трактовать результаты, менять гипотезу, seed'ы, критерий, код или `expected`,
подбирать параметры, исправлять ошибки либо создавать коммиты. Эти решения принимает основной агент с владельцем.
После возврата основной агент проверяет целость и полноту, сам разбирает падения и делает выводы.
Завершённые части и пропущенные/прерванные проверки указывать раздельно; несколько частей не называть цельным прогоном.
